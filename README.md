The Meme Catalogger is a project for the CIT Projects. It was designed to bring a glimpse of humor into someone's day, through it's humourous AI generated captions for memes. The built in search engine uses these captions and tags to allow the user to organize their memes, and help's the user find the right meme at the right situation. This application is optimized for both mac and windows. However, we recommend the user to use a mac due to the fact that processing times are much faster.
